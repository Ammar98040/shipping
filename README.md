# دولابك — متجرك بتصميم الدولاب

متجر إلكتروني بتجربة دولاب **تفاعلية ثلاثية الأبعاد**: **خانات → رفوف → أصناف → منتجات**.

## التقنيات

- **Backend:** Python + Django
- **Frontend:** HTML, CSS, JavaScript (تصميم موبايل أولاً + RTL + تأثيرات 3D)
- **قاعدة البيانات:** MySQL (تطوير) / SQLite (بديل سريع) → PostgreSQL (عند الرفع)

## الميزات الرئيسية

### 🛍️ للعملاء
- **تصميم 3D تفاعلي:** أبواب دولاب تفتح، أدراج تنسحب، منتجات على شماعات
- **نظام المستخدمين:** تسجيل حساب جديد، تسجيل دخول، تسجيل خروج
- **المفضلات (Wishlist):** حفظ المنتجات المفضلة والرجوع إليها لاحقاً
- **طلباتي:** عرض جميع طلبات المستخدم مع التفاصيل والحالة
- **سلة التسوق:** إضافة/حذف/تعديل المنتجات، حساب المجموع الكلي
- **إتمام الطلب:** نموذج شامل لبيانات الشحن والدفع (مع/بدون حساب)
- **تتبع الطلب:** تتبع الطلب برقم الطلب ورقم الجوال (بدون حساب)
- **بحث ذكي:** بحث عن المنتجات مع عرض المسار الكامل
- **فلاتر متقدمة:** فلترة حسب السعر والتوفر (في صفحة البحث فقط)
- **Pagination:** تقسيم المنتجات على صفحات (12-20 منتج/صفحة)

### ⚙️ لوحة الإدارة (`/manage/`)
- **إدارة المستخدمين:** عرض جميع المستخدمين، إحصائيات، تفعيل/تعطيل الحسابات
- **إدارة كاملة:** CRUD للخانات، الرفوف، الأصناف، المنتجات
- **إدارة الطلبات:** عرض جميع الطلبات وتفاصيلها وتحديث حالتها
- **فلاتر ذكية:** فلترة وبحث في جميع القوائم
- **نظرة شاملة:** عرض هرمي قابل للطي للبنية الكاملة للمتجر
- **خصم تلقائي:** خصم المخزون تلقائياً عند إتمام الطلب

### 🎨 التصميم
- **موبايل أولاً:** تجاوب كامل مع جميع الشاشات
- **RTL:** دعم كامل للغة العربية
- **تأثيرات 3D:** أبواب، أدراج، شماعات، بطاقات منتجات بتأثيرات حركية
- **رسوم متحركة:** انتقالات سلسة بين الصفحات

## الهيكل

- **الدولاب (الرئيسية):** خانات بأبواب ثلاثية الأبعاد
- **الخانة:** رفوف على شكل أدراج منسحبة
- **الرف:** أصناف على شكل صناديق على الرف
- **الصنف:** منتجات معلقة على شماعات
- **المنتج:** بطاقة تفصيلية 3D + إضافة للسلة
- **السلة:** عرض المنتجات المضافة + تعديل الكميات
- **الدفع:** نموذج إتمام الطلب
- **تتبع الطلب:** صفحة تتبع بـ timeline تفاعلي
- **البحث:** نتائج مع فلاتر وترقيم صفحات

## التشغيل المحلي

### 1) بيئة افتراضية وتثبيت الحزم

```bash
cd SHOP
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 2) قاعدة البيانات

**خيار أ — تشغيل سريع بدون MySQL (SQLite):**

```bash
set USE_SQLITE=1
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

**خيار ب — استخدام MySQL كما في الإنتاج:**

- إنشاء قاعدة بيانات باسم `shop_db`.
- نسخ `.env.example` إلى `.env` وتعديل بيانات الاتصال.
- عدم تعيين `USE_SQLITE` (أو تعيينه لقيمة غير 1).
- ثم: `python manage.py migrate` و `createsuperuser` و `runserver`.

### 3) الإعدادات الأولى

```bash
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

- المتجر: <http://127.0.0.1:8000/>
- لوحة الإدارة: <http://127.0.0.1:8000/manage/>

### 4) إضافة بيانات تجريبية

**الطريقة السهلة:** استخدم سكريبت التعبئة:

```bash
python populate_data.py
```

هذا سيضيف:
- 4 خانات (الملابس، الشنط، الأحذية، الإكسسوارات)
- 13 رف موزعة على الخانات
- 29 صنف
- 170+ منتج بأسعار ومخزون متنوع

**الطريقة اليدوية:** من لوحة الإدارة (`/manage/`) أضف:
1. **خانات:** الملابس، الشنط، الأحذية، الإكسسوارات
2. **رفوف** لكل خانة (مثلاً: صيفي، شتوي للملابس)
3. **أصناف** لكل رف (مثلاً: تيشيرتات، شورتات)
4. **منتجات** داخل كل صنف

## اللغة

- **عربي فقط** مع دعم RTL كامل من الواجهة
- المشروع مُحسّن للسوق العربي

## الانتقال لـ PostgreSQL عند الرفع

في `config/settings.py` غيّر إعدادات `DATABASES['default']` إلى:

```python
'ENGINE': 'django.db.backends.postgresql',
'NAME': os.environ.get('DB_NAME'),
'USER': os.environ.get('DB_USER'),
'PASSWORD': os.environ.get('DB_PASSWORD'),
'HOST': os.environ.get('DB_HOST', '127.0.0.1'),
'PORT': os.environ.get('DB_PORT', '5432'),
```

ثم شغّل `migrate` على قاعدة PostgreSQL.

## ملاحظات تقنية

- **User System:** نظام مستخدمين كامل مع Django User model
- **Wishlist:** مرتبطة بالمستخدمين المسجلين (علاقة Many-to-Many)
- **Orders with Users:** الطلبات يمكن ربطها بالمستخدم أو بدون (للزوار)
- **Session-based Cart:** السلة مخزنة في الـ session (لا تحتاج تسجيل دخول)
- **Stock Management:** خصم تلقائي للمخزون عند إتمام الطلب + فحص التوفر
- **Order Tracking:** متاح بطريقتين: 
  - للمستخدمين المسجلين: صفحة "طلباتي"
  - للزوار: صفحة "تتبع الطلب" برقم + جوال
- **Pagination:** 12 منتج/صفحة في الأصناف، 20 في البحث
- **Responsive Design:** موبايل أولاً مع دعم كامل للشاشات الكبيرة
