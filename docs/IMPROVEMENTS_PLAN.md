## المرحلة 1 — أمان وموثوقية (أولوية عالية) ✅ مُنفَّذة (أساسيات)

| # | البند | الهدف |
|---|--------|--------|
| 1.1 | توحيد منطق «نسيت كلمة المرور» | `process_forgot_password_step1` + التحقق من الرمز + صفحة كلمة المرور لاحقاً |
| 1.2 | Rate limiting لطلبات OTP | عدّاد لكل بريد + لكل IP في الساعة (`CACHES` + مفاتيح `pwreset:v1:`) |
| 1.3 | بريد غير مسجل | رسالة خطأ صريحة (حسب طلب المشغّل) |
| 1.4 | `logging` بدل `print` | `logger.info` + `logger.debug` للرمز فقط عند `DEBUG=True` |

**تقني:** `store/password_reset_flow.py` + `CACHES` في `config/settings.py` (LocMem افتراضياً).

- استخراج CSS المضمّن من القوالب إلى ملفات تحت `static/css/`.
- مراجعة استعلامات N+1 في قوائم الطلبات/الشحنات.
- توحيد مكوّنات القوالب المشتركة (رأس، تنبيهات، أزرار).
- **مُنجز:** تقسيم `store/views.py` إلى واجهة رقيقة تستورد من `views_storefront.py` (واجهة المتجر) + `views_support.py` + `views_webhooks.py`؛ منطق الدردشة الداخلية في `internal_chat_service.py`؛ إشعارات الإدارة في `views_manage_notifications.py`؛ مزخرفات `_staff_required` في `manage_decorators.py`. قوالب الدردشة الداخلية موحّدة عبر `templates/partials/internal_chat_body.html` و `internal_chat_compose_js.html`. يبقى اختياري: تقسيم إضافي لـ `views_manage.py` حسب المجال.
