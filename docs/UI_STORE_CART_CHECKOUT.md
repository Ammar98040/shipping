# واجهة المتجر — تقدم التحسين

## مكتمل
### السلة والدفع
- `store-flow.css` — خطوات الشراء، ثقة، تركيز/حركة مخففة.
- `cart.html` / `checkout.html` — عناوين فرعية، رجوع، Turnstile/إرسال (سابقاً).

### التصفح والرئيسية وطلباتي
- **الدولاب:** `wardrobe.html` + شريط ثقة تحت الشعار.
- **خانة / رف / صنف / منتج:** مسار تصفح موحّد `store-breadcrumb-nav` + `store-flow.css`.
- **طلباتي:** عنوان فرعي، شريط ثقة، فراغ محسّن.

### تفاصيل الطلب، التتبع، المفضلة، البحث، اتصل بنا، عن المتجر
- **`order_detail`:** مسار «طلباتي › طلب #…»، شريط اختصارات، عنوان فرعي، شريط ثقة.
- **`order_track`:** مسار من الدولاب، شريط ثقة، روابط «بحث جديد» ضمن `store-quick-toolbar`.
- **`wishlist`:** مسار موحّد، اختصارات (سلة / الدولاب / طلباتي)، ثقة، `.empty-hint` عند الفراغ.
- **`search`:** مسار، عنوان فرعي، ثقة، تحسين حالة «لا استعلام».
- **`contact` / `about`:** `store-static-pages.css` + مسار + ثقة؛ إزالة تكرار `base.css` من القالب.

## الملفات المشتركة
- `static/css/store-flow.css` — يُحدَّث بـ `?v=3` في القوالب.
- `static/css/store-static-pages.css` — صفحات ثابتة (اتصل بنا، عن المتجر).

## التالي (اختياري)
- توحيد الأنماط المضمّنة (inline `<style>`) في `order_detail` و`order_track` إلى ملفات CSS خارجية.
- صفحات أخرى نادرة الاستخدام (سياسة خصوصية، شروط، إلخ) بنفس المسار والثقة.
